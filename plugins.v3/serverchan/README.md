# Server酱³通知 (serverchan)

通过 Server酱³ 发送消息通知，支持 APP 推送。

## 功能

- 🖼️ 入库通知支持封面图片
- 📥 下载任务添加通知
- 🗑️ 下载任务删除通知
- ✅ 媒体整理完成通知
- 📺 订阅完成通知
- ❌ 系统错误通知
- 💬 用户消息通知

## 配置

| 参数 | 说明 | 获取方式 |
|------|------|----------|
| UID | Server酱³ 用户 ID | [https://sc3.ft07.com/](https://sc3.ft07.com/) 注册获取 |
| SendKey | Server酱³ SendKey | 同上 |
| 标签 | 消息标签列表 | 多个标签用竖线(\|)分隔 |
| 消息类型 | 选择需要接收的通知类型 | 不选则接收所有 |

## 安装方式

1. 打开 MoviePilot 设置 → 插件 → 插件源
2. 添加插件源：`https://github.com/SilentReed/MoviePilot-Plugins`
3. 在插件市场搜索「Server酱³通知」并安装
